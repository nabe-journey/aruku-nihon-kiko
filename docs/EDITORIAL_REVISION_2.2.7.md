# 2.2.7 抄訳と挿絵の連動改訂

- **泊まれ、泊まれと引き止められ**（hodogaya）：旅籠の客引き場面で省略された馬方と馬の掛け合いを復元。参照原文キー `01-05`。段落 4→5。
- **白い幽霊の正体**（hamamatsu）：幽霊騒動の翌朝、木のぼた餅を看板と知らずかじり、本物を鳶に奪われる二段の失敗談を復元。参照原文キー `03-09`。段落 5→7。
- **一足の草鞋で、どこまでも？**（arai）：次の白須賀篇の銭の発見と酒代騒動の発端となる駕籠の乗換えを補った。参照原文キー `04-01`。段落 4→6。
- **三文の餅を、二文で買う算段**（okazaki）：茶屋の見送りと三味線の駒・馬の洒落を、菓子屋の騒動の前に戻した。参照原文キー `04-08`。段落 4→5。
- **大坂のはずが、また伏見**（wrong-boat）：船乗換えの具体的原因と、伏見から京都への道中で起きる甘酒屋の小話を復元。参照原文キー `06-01`。段落 4→6。

既存原作挿絵の点数・配置、広重鑑賞文、進捗・距離・保存用IDは変更していません。新規原作挿絵の採用・刷年確定は今回行っていません。
