# 非早稲田原作挿絵の再確認（2.3.1）

## 方針

- 早稲田画像は転載しない。
- 採録する場合は、**国文研/CODHなどの公開利用条件が明確な非早稲田画像**を優先する。
- ただし、図像と抄訳の場面対応が弱い場合は追加しない。

## 今回の結論

- 既存の27点は引き続き**国文学研究資料館所蔵／CODH提供**の画像を正本として維持。
- 未採録篇について、既存の `hizakurige-reading-review.json` と `HIZAKURIGE_ILLUSTRATION_AUDIT.md` を再確認したが、**今回の作業範囲では新規採用に足る図は増えなかった**。
- したがって、2.3.1では画像点数を増やしていない。

## メモ

次回以降に追加調査を続ける場合も、
1. 先に該当篇の原文アンカーを特定
2. 図像コマの本文位置を確定
3. 抄訳段落との対応を明記
4. そのうえでのみ画像を追加

の手順を守る。
